# UMCG cohort staging area (UMCGCohortsStaging)

In this profile the target of `Variable mappings` refers to the schema `UMCG` (the catalogue schema of that server).
This profile has no `Dataset mappings` and no `useExternalDefinition`.

- `Datasets.csv` becomes `Tables.csv`.
- `dataset`, `source dataset` and `target dataset` become `table`, `source table` and `target table`.

# catalogue_flat

Profile DataCatalogueFlat. Five rows from the demo data:

- `UMCG` (type Catalogue) and `LifeCycle` (type Network,Catalogue) go to `Catalogues.csv`;
- `testNetwork2` (type Network) goes to `Networks.csv`;
- `GECKO` and `ALSPAC` (type Cohort study) go to `Collections.csv`.

Text values that look empty must not change: `testNetwork2` has acronym `NA`, and `GECKO` has acknowledgements `None`.
`Subpopulations.csv` refers to the collections and does not change.
